# 变体：哪些锁死，哪些放开

一套规则要被很多产品拿去用。目标是：**放在一起看得出是同一套语言，分开看又不是同一个产品。**

办法是把「骨架」和「外皮」分开。骨架每次照做，外皮在开工前定一次，之后整站沿用。

## 锁死的部分

下面这些动了，就不是这套东西了。

| 锁什么 | 原因 |
| --- | --- |
| 深底或纸面，二选一，不混着用 | 一册档案只有一种纸 |
| 单一强调色，只出现在线、编号、当前项与印章上 | 线是档案的边界，面是促销的语法 |
| 全部直角；异形靠切角与角花 | 实测按钮、面板、卡片都是直角 |
| 中文宋体，英文 Didone 大写、宽字距 | 辨识度主要在这儿 |
| 编号、日期、页数、状态一律真数据，等宽数字 | 编出来的数字会让整页失真 |
| 红色只给时间语义（告急、过期、中断） | 红色是「过期」，不是「危险」 |
| 动效只有淡入与位移，500 / 350ms | 这套东西的旧，来自慢 |
| 一屏内：网点 ≤ 1 处、竖排英文 ≤ 1 处、锈红标记 ≤ 4 处 | 稀少才显得是标记 |

## 放开的六个维度

| 维度 | 取值 | 落在哪 | 限制 |
| --- | --- | --- | --- |
| **强调色** | `rust` 赭红（默认）、`amber` 琥珀、`verdigris` 铜绿、`gold` 暗金 | `<html data-accent="…">` 或 `--r99-accent` | 字压在上面 ≥ 4.5:1；避开粉与紫；一个产品只用一种 |
| **表面** | `void` 近黑、`deep` 深褐、`paper` 米纸 | `data-theme` | 纸面要整套换，不能只染一块 |
| **切角** | `none`、`sm` 10px、`lg` 18px | `--r99-cut` 配合 `.r99-cut` | 只切一个角，其余保持直角 |
| **质感** | `rain` 雨丝、`halftone` 网点、`paper` 纸纤维、`plain` 无 | `data-texture` | 不能压过文字；颗粒 ≤ 6% |
| **密度** | `compact`、`standard`、`roomy` | `data-density` | 点击区仍要 ≥ 44pt |
| **动效** | `full`、`calm` | `data-motion` | `calm` 去掉入场，保留悬停与浮层进出 |

四个强调色在深底上的实测对比：

| | rust | amber | verdigris | gold |
| --- | --- | --- | --- | --- |
| 色值 | `#B55829` | `#C97A2B` | `#4F7D6A` | `#B08D4F` |
| 当线用 | 4.1:1 | 5.9:1 | 4.2:1 | 6.4:1 |
| 上写奶白 | 4.7:1 | 3.2:1 | 4.6:1 | 3.0:1 |
| 上写墨色 | 3.9:1 | **5.5:1** | 3.9:1 | **6.0:1** |

所以填色按钮的字色不是固定的：rust 与 verdigris 配奶白，amber 与 gold 配墨色。自定义颜色时把这张表重算一遍。

**有两件事不在属性里，却最能拉开距离：**

- **主视觉**：封面正中放什么。档案产品放真实卷宗封面，活动页放当年海报，工具放自己的主图表。模板里的钟楼、拱门、电波都只是占位。
- **图源**：这套味道有一半来自影像。用产品自己的照片或插画，3:4 或 16:9 裁切、1px 边框、直角。没有图就画抽象图形，别用灰色占位块。

## 四套预设

拿不准就从这里挑一套，再改一两项。

| 预设 | 适合 | 强调色 | 表面 | 切角 | 质感 | 密度 | 动效 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `archive` 档案 | 内容站、资料库、个人站，最接近默认 | rust | void | lg | rain | standard | full |
| `nightrain` 雨夜 | 监控、运维、长时间盯屏 | verdigris | deep | lg | rain | standard | calm |
| `salon` 酒会 | 活动、邀请函、品牌页 | gold | void | sm | halftone | roomy | full |
| `dossier` 卷宗 | 文档、合同、打印友好的后台 | rust | paper | none | paper | compact | calm |

同一页的四套效果：`examples/web/showcase-1440.jpg`（archive）、`preset-nightrain-1440.jpg`、`preset-salon-1440.jpg`、`preset-dossier-1440.jpg`。

## 定下来之后

1. 先想清楚三件事：谁在用、在什么光线下看、要不要打印。夜间长看选 `nightrain`，要打印选 `dossier`。
2. 写一张变体卡，放在交付说明的最前面：

   ```text
   变体：雨夜（verdigris / deep / lg / rain / standard / calm）
   主视觉：夜间值班台照片，裁 16:9
   页面类型：档案库为主，详情用卷宗
   ```

3. 只在**一处**落地：网页写 `<html>` 的 `data-*`（或用 `assets/variant.js` 读 `?variant=`）；Flutter 用 `R99Palette.copyWith` 与 `R99Accents`；原生改一份主题常量。部件上不要再单独写颜色。

## 模板是参考，不是版式

- 先列清这一屏要回答什么、有哪些真实字段，再挑部件，最后才排位置。
- 占位内容必须全部换掉：钟楼、拱门、`N-0421`、`1999.12.31`、`档案员 · 林`。
- 网格不是默认解。条目超过 8 条、且用户要比对字段时，用记录行或表格。
- 交付时挑最接近的模板对比一次，说明这个产品在哪三处与它不同：主视觉、版式、部件组合、或变体。

## 没有现成部件时

不要临时发明一套样式。按下面的顺序，从已有规则里推：

1. **它表达什么状态？** 当前 / 可点 / 需注意 → 小面积锈红或 1px 锈红线；已完成 → 奶白或墨色实心；封存 → 灰线。
2. **能不能按？** 能按的切一个角（10 或 18）；不能按的保持直角。
3. **带不带真数据？** 编号、日期、页数用 Didone 等宽数字，与中文标签成对出现。
4. **边界在哪？** 1px 线，色值为字色的 16%；当前项的线加粗到 2px 并换锈红。
5. **怎么动？** 进入 500ms、退出 350ms、悬停与按下 200ms 变暗；不做位移放大。
6. **收尾自检**：深色与纸面都看一遍，减少动效、键盘焦点、读屏是否成立。

例子：**步骤条**。每步一格，写 `01`、`02` 与中文名。当前步用锈红细线加奶白字，已经走过的用墨色实心、编号反白，没到的用灰线。能点回去的步在右上切一个角，不能点的保持直角。步与步之间 1px 灰线，已走过的一段换成锈红。当前步加 `aria-current="step"`；切换只做 200ms 的颜色过渡，不做滑轨动画。
