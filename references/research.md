# 来源与测量：1999 的界面

2026 年 10 月对《重返未来：1999》官网（`re.bluepoch.com`）、玩家 wiki（`res1999.huijiwiki.com`）与公开截图做的第二轮整理。
官网是 jQuery + 图片堆出来的单页，可读的样式有限；wiki 有 Cloudflare 验证，但 MediaWiki API 能取到解析后的页面与内联 CSS，
功能层的规律主要从那里量。

标记：**【测】** 从样式表读出；**【看】** 从截图看到；**【猜】** 推测，没有直接证据。

| 亮橙：活动、轮播指示条 | `#DB6F39` / `#FF9E34` | 【测】 |

## 提示条与复现条（2026-10 补测）

来源：`右上角提示条(忽略提示条以外的背景).png`（405×155）、`战斗中右上角快捷重复战斗扫荡提示框右上角是圆角其余方 (1).png`（303×133）。

- **提示条**：右上角面板，四角直角（放大 6 倍核对，边缘只有抗锯齿，没有弧）。米色渐变 `#F2ECE6 → #E9DCD2`，左侧 42px 圆圈「!」，描边 `#B0472F`，正文 19px 墨色，数字走 `#B0472F`。距边 24px，2.6 秒消失。
- **战斗复现条**：深灰 `rgba(34,38,38,.84)` + 1px `rgba(255,255,255,.55)` 边 + **仅右上角 14px**；左侧三个 7px 方块，中文 22px、英文 10px/0.34em。它是状态条，不自动消失。
- **新信息标记**：正方形色块（约 8px），不是圆点；未读数用带数字的小方块。
- **多条提示条**：从屏幕外右侧滑入，左右移动约一个面板宽，约 200ms；两条之间间隔约 0.3 秒，纵向堆叠；消失按出现顺序，先出现的先消失，向上淡出。
- **物品格**：深底 + 稀有度底部辉光，底部 14% 半透明计数条 + 3px 亮色底边；不是整块底色。
- **图标栏**：图标在上、标签在下（约 40px 图标 + 13px 文字），条目约 78×72。

## 形状与切角

- 通用边框：`1px solid #B55829`，官网与 wiki 一致【测】。
- 不对称圆角：`border-radius: 0 30px 0 0`（wiki 信息框）【测】。
- 官网圆角档位：`10 / 11 / 20 / 45px`，按钮是圆角矩形而不是切角【测】。
- 悬停：图片只加 `1px solid #B55829`，不位移、不缩放、不加阴影【测】`papermask.css`。
- 面板：`#000000D0` 上再压 1px 锈红线，内容白色【测】。
- 半色调网点：登录提示条的底纹【看】。
- 玻璃：`backdrop-filter` + 全屏背景图【测】。
- 遮罩与图层：官网用整层 `papermask` 做纸页式弹层，宽 100%、高 93%、顶部 7vh 起始【测】。

**结论**：游戏内界面一律直角，官网营销页的圆角只作来源记录，不采纳。早期把投影与抗锯齿读成「5–6px 小圆角」，已作废（见第 10 节）。

## 版式、编号与标注

- 中文标题粗、字距略大；正文行高约 1.9【看】。
- 英文眉标在中文之上或之侧，全大写、字距很宽（`R E V E R S E`）【看】。
- wiki 侧栏有 90° 旋转的英文小字（`rotate: 90deg`，10px）【测】。
- 编号与日期是可检索的真数据，日期用点分 `1999.12.31`【看】。
- 状态用色点 + 文字，不用徽章堆叠【看】。

## 6. wiki 的价值：功能层

官网只有氛围（满屏 KV、三个下载按钮、立绘轮播），**wiki 才是这套风格落到可用界面的样本**：

- 信息框：黑面板 + 锈红线 + 内部滚动；
- 按钮组：黑底小块 + 底部中文标题 + 竖排/侧置英文；
- 轮播指示条：2px 线，当前 4px；
- 时间状态：绿 / 灰 / 红三态，直接对应活动进行中、已结束、告急；
- 标题装饰：`drop-shadow(0 0 5px #ffffff80)` 的浅描边。

这些是「1999 风格做内容站」的真实解，比官网更适合借鉴。

## 采用与舍弃

| 借 | 不借 |
| --- | --- |
| 锈红 1px 细线、半透明黑面板 | 官网全屏摄影背景、wiki 的 fullbg 插图 |
| 宋体正文 + Didone 大写字距 + 竖排英文 | 官方字体文件（思源宋体可自由分发，Didot 不可） |
| 米纸 / 奶白 / 时间三态 | 角色立绘、CG、logo |
| 半色调网点、纸页遮罩、玻璃模糊 | 具体游戏文案、活动名 |
| 编号、日期、页数、状态 | 假技术文字、条形码、装饰刻线 |

## 10. 从 wiki 图鉴量到的卡面语言

wiki 的图鉴页是同一套模板渲染的，可以直接读到 data 属性与卡面底板图（`huiji-public.huijistatic.com` 未设防）。2026 年 10 月实测：

| 页面 | 条目数 | 用的部件 | 稀有度范围 |
| --- | --- | --- | --- |
| 物品列表 | 1,008 | `character-list-block` 方卡 + 底板图 | 0–5（六级） |
| 角色列表 | 138 | `character-list-block` 竖卡 + 立绘 | 1–5 |
| 心相列表 | 132 | 与物品相同的方卡 | 1–5 |
| 衣着列表 | 161 | 竖卡 | 1–5 |
| 荒原列表 | 494 | `item-link` 小链接 + 稀有度框 | 1–5 |

**两种卡系统**：方卡（物品/心相）与竖卡（角色/衣着），外加小尺寸的 `item-link`。三者共用同一组稀有度底板图 `Bgequip1..6.png`。

**稀有度的实现方式**（这是最关键的一条）：不是描边，而是**白卡纸 + 底部色带**。底板图实测色带：

| 等级 | 色带 | 卡面 | 备注 |
| --- | --- | --- | --- |
| Ⅰ | `#C6C6C6` | `#FFFFFF` | 只有物品用到这一级 |
| Ⅱ | `#496441` | `#FFFFFF` | |
| Ⅲ | `#545C7D` | `#FFFFFF` | |
| Ⅳ | `#A672B2` | `#FFFFFF` | |
| Ⅴ | `#DBC379` | `#F3E8CF` | 卡面转米色 |
| Ⅵ | `#CC7722` | `#E9D8AF` | 再加颗粒 |

**角色卡**：白卡（`Bg_kapaidi.png` 292×600，全角小圆角、无描边、有柔和投影）+ 立绘裁切 + 左上稀有度 + 底部属性。数据属性齐全：`data-rare`、`data-career`（职介 1–6）、`data-dmgtype`（1–2）、`data-gender`、`data-battletag`。

**本套件的取舍**：全部直角。放大核对按钮底 tn_3、tn_querenanniu、角色卡底 g_kapaidi 都是直角；早前脚本报出的「5–6px 圆角」是把投影与抗锯齿算成了圆角，已作废。

## 11. 局限

- 官网样式里可读的按钮、圆角数值来自截图目测，标【看】的条目误差在几个像素内。
- 游戏内 UI 的截图没有逐张量；本规范以官网与 wiki 的可读样式为准，再加入少量为可用性做的推导。
- 1999 的辨识度很大一部分来自手绘立绘与摄影背景。本套件用「可生成的质感层 + 产品自己的图」替代，**不宣称能复刻游戏画面**。

## 9. 还缺什么：游戏内界面

**当前规范只覆盖到「官网 + 内容站」这一层。** 游戏内的部件语言（卡框、道具格、战斗 HUD、抽卡结果、确认弹窗）没有可读样式表，必须靠截图补。以下八张能补上大部分空白：

| 需要拍 | 要量什么 |
| --- | --- |
| 主界面 / 大厅 | 顶部资源栏、侧边、底部入口的形状与描边层级 |
| 角色详情 | 卡框是否双层线、角花、立绘裁切、属性排版 |
| 背包 / 仓库 | 道具格比例、稀有度颜色、选中态 |
| 战斗 HUD | 血条与激情点的形状、数字字体 |
| 抽卡结果 | 大卡出场构图、星级表现、光效 |

| 设置 / 列表 | 行高、分隔线、开关控件 |
