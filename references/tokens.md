# 数值：颜色、字阶、尺寸

平台无关的数值在 `assets/tokens.json`；网页里的定义在 `assets/reverse1999.css` 开头（`--r99-*`）。
对比度按 WCAG 公式实测，不是估的。

**红色只表示时间**。删除按钮改用锈红描边 + 二次确认；不要用红。

### 用色规则

- 一屏里锈红的面积要小：线、编号、当前项、印章，四处以内。
- 锈红不做大面积填充。主按钮的锈红填充是「小块」的上限。
- 不黑底配锈红大字（4.1:1，读起来吃力）；大字标题用奶白。
- 图表不用红绿；用锈红与灰阶，状态另加图标或文字。

## 字体

| 变量 | 字体 | 用在 |
| --- | --- | --- |
| `--r99-serif` | Noto Serif SC / 思源宋体 / Songti SC / SimSun | 一切中文：正文、标题、按钮、标签 |
| `--r99-display` | Bodoni Moda / Didot / Playfair Display | 英文大字标、编号、日期、眉标、金额 |
| `--r99-mono` | 系统等宽 | 只给代码 |

| 字号 | 值 | 用途 |
| --- | --- | --- |
| display | `clamp(40px, 7vw, 76px)` | 封面大字标 |
| title | `clamp(28px, 3.4vw, 40px)` | 页面标题 |
| h2 | 28px | 章节标题 |
| h3 | 20px | 小节标题 |
| body | 16px / 行高 1.9 | 正文 |
| small | 14px | 说明、列表名 |
| meta | 12px | 日期、编号 |
| label | 11px | 眉标、字段名 |

- 拉丁眉标：全大写，字距 `0.22em`，行高 1.4。
- 拉丁大字标：字距 `0.04em`，行高 1.04。
- 中文标题字距 `0.04–0.1em`，正文 `0.01em`。
- 数字一律 `tabular-nums`。
- 竖排英文：`writing-mode: vertical-rl` + `rotate(180deg)`，字距 `0.32em`，一屏最多一处。

## 尺寸

| 变量 | 值 | 用途 |
| --- | --- | --- |
| 间距阶 | 4 / 8 / 16 / 24 / 40 / 64 / 96 | 组件内外边距、段落间距 |
| 圆角 | 0 | 一律直角；异形用 clip-path 切角 |
| 线宽 | 1 / 2 / 4 | 边界 1、当前项 2、指示条 4 |
| 容器 | 1180 / 40em / 430 | 桌面版心 / 正文宽度 / 手机宽度 |
| 点击区 | ≥ 46px 高，≥ 44pt | 按钮与链接 |

**圆角一律 0**。唯一例外是战斗复现条 `.r99-replay` 的右上角 14px（素材原图确认，其余三角仍为直角）。圆形只用于两处：状态点与提示条的「!」徽记。

## 质感层

1999 的辨识度有很大一部分来自照片。没有照片时，用五层可生成的质感代替，顺序很重要：

1. **底光**：两团大半径径向渐变，冷蓝 `rgba(46,68,79,.5)` 在左上、暖褐 `rgba(88,44,26,.42)` 在右上，压近黑。
2. **雨丝**：`repeating-linear-gradient(101deg, rgba(226,236,240,.055) 0 1px, transparent 1px 9px)`，加 `blur(.4px)`，用径向遮罩让画面中心更淡。
3. **颗粒**：160px 平铺的 `feTurbulence` 灰度噪声，深色用 `overlay 5.5%`，浅色用 `multiply 4%`。
4. **暗角**：径向压暗到 `rgba(0,0,0,.55)`。
5. **网点**：6px 周期、1.5px 圆点，只用于小标签的底（一屏一处）。

纸面：`#E9DCCD` 底 + `repeating-linear-gradient(0deg, rgba(23,19,16,.035) 0 1px, transparent 1px 4px)` 的横向纤维。

原生平台对应：噪声用 `feTurbulence` 预渲染成 PNG 平铺；雨丝用一张 512×512 PNG；暗角用径向渐变图层。**不要**在运行时实时生成噪声。

## 动效

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--r99-t-enter` | 500ms | 入场 |
| `--r99-t-exit` | 350ms | 退出 |
| `--r99-t-hover` | 200ms | 悬停、描边、颜色 |
| 位移 | 32px | 入场位移，退出为 16px |
| 错开 | 60ms | 一组卡片依次入场 |
| 慢转 | 60s / 圈 | 徽记、唱片 |
| 缓动 | `cubic-bezier(.22,.61,.36,1)` 入场；`cubic-bezier(.33,0,.2,1)` 退出 | — |

没有弹跳、缩放、发光、视差。`prefers-reduced-motion` 与 `data-motion="calm"` 下全部关闭。

| Ⅲ | `#545C7D` | `#EEF1F7 → #B9C2D8` | 无 |
| Ⅳ | `#A672B2` | `#F4EEF6 → #C9A9D2` | 无 |
