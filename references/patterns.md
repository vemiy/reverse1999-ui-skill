# 页面怎么排

各页面类型共用同一套颜色与部件，差别在「敢不敢大」。前四类给了骨架，骨架下面写了这一屏必须回答的问题；后四类用一段话说明结构、部件与禁忌。

## 一、封面

用在首页、落地页、启动页、活动页。一屏只放一个主张。

```text
┌ 页眉 ──────────────────────────────────┐
│ 字标                      导航    主按钮 │
├ 影像 ──────────────────────────────────┤
│ 眉标                                     │
│ 大字标（两行，第二行更重）               │
│ 英文副标（大字距）                       │
│ 导语（≤ 2 行）                           │
│ 主按钮  次按钮                           │
│ 编号 │ 日期 │ 状态                       │
│                              [竖排英文]  │
│                                    [01]  │
└──────────────────────────────────────────┘
```

必须回答：这是什么、给谁、现在能做什么。三件事之外的都删掉。

- 大字标两行、每行 ≤ 8 个汉字；第二行可以更重或换成锈红 `<em>`。
- 导语两行以内；再多就移进下一节。
- 右上大编号用空心描边（`-webkit-text-stroke`），与章节编号呼应。
- 竖排英文放右侧，与页脚边缘留 40px。
- 影像必须是自己的图；没有图时用抽象插画，不要渐变占位。

## 二、卷宗

用在详情、长文、说明、帮助。读者在这里停留最久，排版优先。

```text
┌ 页眉 ──────────────────────────────────┐
│ 面包屑（档案 / 分类 / 编号）             │
│ 标题（30–52px）                          │
│ 导语                                     │
│ 字段对 ×4                         [印章] │
├ 版本页签 ───────────────────────────────┤
│ 正文（40em）              │ 目录（吸顶） │
│  首字下沉                  │ 调阅面板     │
│  二级标题                  │ 排队进度     │
│  引文                      │ 主按钮      │
│  表格 / 图                 │             │
│  脚注                      │             │
│  上一份 / 下一份            │             │
└──────────────────────────────────────────┘
```

必须回答：这是什么、谁经手、能不能用、下一步做什么。

- 字段对固定四项：日期、经手人、页数、状态；超过四对改表格。
- 目录只列二级标题；当前项 2px 锈红；整块吸顶。
- 正文 40em；表格与图可以突破到 100%，但左边缘对齐正文。
- 脚注用编号列表，正文里用上标数字，不用星号。
- 上下篇用「编号 + 标题」，不用「上一篇 / 下一篇」单独出现。

## 三、档案库

用在列表、检索、管理。用户来这里找东西，不是来读。

```text
┌ 页眉 ──────────────────────────────────┐
│ 标题 + 一句统计            检索（下划线）│
├ 工具栏 ────────────────────────────────┤
│ 筛选 chip ×4                    排序说明 │
├ 结果 ──────────────────────────────────┤
│ 卡网格（3:4 图）或记录行（编号/日期/名称/状态）│
│ ……                                       │
├ 分页 ──────────────────────────────────┤
│ 第 1–8 条，共 1,024 条     上一页  下一页 │
└──────────────────────────────────────────┘
```

必须回答：有多少、怎么筛、每条是什么、怎么进去。

- 少于 8 条且有图：卡网格；超过 8 条或要比较字段：记录行。
- 筛选 chip 带真实计数；选中态锈红填充。
- 结果上方永远有一句「第几条到第几条，共多少条」。
- 分页按钮只有两个；页码用指示条，不做数字串。

## 四、看板

用在后台总览、监控、值班台。用户在这里看「现在怎么样」，不是来读内容。

```text
┌ 页眉 ──────────────────────────────────┐
│ 字标                    导航     导出   │
├ 左栏 232 ┬ 标题 + 日期 + 系统状态 ────┤
│ 01 总览  │ 指标 ×4（数字大、标签小）     │
│ 02 入档  │ ┌ 柱图 ──────┐ ┌ 队列 ─────┐ │
│ 03 调阅  │ │ 本周入档     │ │ 进度 6/12 │ │
│ 04 复制  │ └─────────────┘ └───────────┘ │
│ 05 成员  │ ┌ 待核列表（记录行）─────────┐ │
│ 06 权限  │ └────────────────────────────┘ │
│          │ ┌ 最近操作（表格）───────────┐ │
└──────────┴─┴────────────────────────────┘
```

必须回答：现在有多少、有什么要处理、谁在做什么。

- 指标固定四个，数字用 Didone 40px，单位与说明用 12px；超过四个就换一屏。
- 只有一张图；柱状用锈红，休息日或异常值用灰，不加网格线。
- 队列用 `.r99-meter` 显示「已用 / 上限」，不只写数字。
- 待核用记录行，右侧状态写「超时 27 小时」这类真实差值；超时的圆点用红。
- 最近操作是表格，四列：时间 / 操作人 / 动作 / 卷宗。
- 左栏导航编号固定，当前项 2px 锈红；移动端塌成横排 chip。

## 五、陈列板

陈列板用在个人档案、角色页和单件藏品：左栏一张贴上去的展品配悬挂证件牌，右栏一张钉住的纸质档案加一列纵向数据卡，底部一行徽章收尾。部件固定为证件牌 `.tag`、纸质档案 `.paper`、数据卡 `.stat`（陈列板专用，与看板的 `.r99-stat` 不是同一个）、徽章 `.badge`；抬头是三格元数据（整理 / 更新 / 状态），块与块之间用点状线断开。展板内部是固定暗色的陈列柜，底色、纸张、数据卡都不随明暗主题反转，柜框靠内外两层细线与四角短线。禁忌：展品与纸张倾斜不超过 2°，只有悬挂证件牌（−7°）与印章（−3° 至 −4°）可以更斜；数据卡只纵向单列、右缘切角，不排网格；徽章只描线不填色，一行放不下就换行，不缩尺寸。

## 六、邮件

邮件用在站内信、通知与附件领取：顶栏放返回、标题、总数与批量操作，主体是固定宽度左列表加自适应右阅读区。列表行四段——8px 未读方块、发件人与日期、主题、编号；阅读区是一张内外双框的纸面板，正文之后接附件条，最后落签名。附件条固定三栏：46px 文件图标、文件名与格式大小期限、一个领取按钮；窄屏时按钮整行落到下方。禁忌：未读只用方块不用圆点；切换邮件只改阅读区内容，不整页刷新、不另开窗口；一封信只放一条附件条，多个文件在条内并列文件名。

## 七、商城

商城页用在购买、兑换与货架浏览：顶栏一排货币（名称、余额、一个小号补充按钮），下面接分区导航，左侧商品格、右侧吸顶的购买面板。商品格是正方形 `.r99-item`，格内底条左写单价右写库存，格子外上方单独一行剩余天数；稀有度只靠底部 3px 亮边与向上的辉光表现，等级文字写在购买面板里。购买面板自上而下为库存标、名称与编号、稀有度方块、单价、数量步进、合计、主按钮，步进上限取限购数与库存中较小的那个。禁忌：稀有度不铺满整格；面板里的数字必须与格子、步进同步；货币条不做充值横幅，补充只留一个加号。

## 八、加载

加载用在启动、调取与切场：满屏门形徽记居中，顶部一行眉标，中央是标题块（标题、英文、副标、记录编号），底部左是状态文字与 2px 进度线、右是一句档案引文。门形徽记只让中轴与顶端菱形走强调色，其余线条一律低对比灰。进度线宽即真实进度，右端用 1px 竖线收口，上方标「47 / 100」这类真实计数。禁忌：不用旋转图标、省略号动画与循环假进度；引文一屏一句并注明出处；加载过久要换成可返回的出错状态。

## 手机

```text
┌ 顶栏（字标 + 明暗 + 筛选）┐
│ 主卡片（16:9 影像 + 标题 + 编号）│
│ 横滑筛选 chip               │
│ 记录行 ×4                   │
│ 纸面板（表单 / 预约）        │
├ 底部标签栏（4 项）           ┤
└ 底部面板（筛选 / 操作）      ┘
```

- 顶栏高度 ≤ 56px；标题只在卡片里出现，不重复。
- 记录行在手机上隐藏日期列，保留编号与状态。
- 底部标签栏固定，当前项 2px 锈红短线；留 `safe-area-inset-bottom`。
- 底部面板直角，顶部一条 2px 强调色线，把手 40×2 线，操作按钮贴底。

## 状态

| 状态 | 写法 |
| --- | --- |
| 空 | `.r99-empty` + 一句完整的话，说明将来会出现什么 |
| 加载 | 2px 锈红进度线，或灰线骨架块；不加闪光 |
| 出错 | 锈红细线面板 + 一句原因 + 一个「重试」按钮；不用红色背景 |
| 无权限 | 说明「谁能看」与「怎么申请」，给一个按钮 |
| 超出 | 显示总数与「缩小筛选范围」的建议，不隐藏数据 |
