# 取舍：每条都有理由

每一条都有一个理由。理由比条目重要：换产品时条目可能不适用，理由不会变。

## 颜色

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 锈红只做 1px 线、编号、当前项、印章 | 大面积锈红底、锈红渐变 | 4.1:1 的色做面会变成促销条，且不可读 |
| 深底写奶白，纸面写墨色 | 深底写锈红大字 | 4.1:1 低于正文门槛，长看会累 |
| 用灰阶与锈红做图表 | 红绿对比、彩虹色板 | 状态另有文字与图标，颜色只做辅助 |
| 红色只给「告急 / 过期 / 中断」 | 红色删除按钮 | 档案里红色表示时间，不表示危险 |
| 强调色一屏 ≤ 4 处 | 每个按钮都用强调色 | 少才有指向性 |

## 形状

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 全部直角；切角表示装饰与异形 | 胶囊、圆角、投影卡片 | 实测按钮与面板底图均为直角，圆角是把投影误判了 |
| 1px 细线分区 | 卡片套卡片、投影分层 | 线是档案的边界，投影是商品橱窗 |
| 图片 1px 边框 + 直角 | 圆形头像、白色描边、圆角相框 | 照片在档案里是「贴上去的」 |
| 图标用细线，1.5px 描边 | 面性图标、彩色图标 | 与细线体系一致 |

## 字体

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 中文全部宋体 | 标题宋体、正文黑体 | 一半宋一半黑，整页立刻散 |
| 英文用 Didone 大写 + 0.22em 字距 | 英文用无衬线、混用三种字体 | 字距是这套风格最明显的标记 |
| 数字用等宽数字 | 比例数字、中文数字混排 | 编号与日期要对齐 |
| 正文 16px / 1.9 行高 | 正文 14px / 1.5 行高 | 宋体小字号发虚 |
| 竖排英文一屏一处 | 每节都竖排 | 多就不特别了 |

## 内容

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 编号、日期、页数来自真实数据 | 假编号、假坐标、假文件大小 | 假数据会被当真，且删掉不影响信息 |
| 空状态写一句完整的话 | 「暂无数据」+ 大图标 | 用户需要知道这里将来会出现什么 |
| 按钮写动作（保存、申请调阅） | 写风格词（开启旅程、进入档案） | 界面不是文案练习 |
| 英文眉标是中文的直译 | 「ARCHIVE OF SOULS」这类创作 | 眉标是标签，不是标语 |

## 动效

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 淡入 + 32px 位移，500ms | 弹跳、缩放、旋转入场 | 旧机器不会弹 |
| 悬停变暗 6%、按下变暗 14%，200ms | 悬停变亮、位移、放大 | 游戏里按下是「压下去」，不是「亮起来」 |
| 一组卡片错开 60ms | 全部同时出现或错开 200ms 以上 | 依次出现像翻页，等太久像卡顿 |
| 尊重 `prefers-reduced-motion` | 无视系统设置 | 眩晕是真实存在的无障碍需求 |

## 无障碍

| 做 | 不做 | 为什么 |
| --- | --- | --- |
| 点击区 ≥ 46px 高 | 14px 小链接当按钮 | 触屏手指不是鼠标 |
| 当前项有颜色 + 2px 线或加粗 | 只靠颜色区分 | 色盲用户看不出锈红与灰 |
| 焦点框 2px、偏移 3px | `outline: none` | 键盘用户需要位置 |
| 对话框 `role="dialog"` + Esc 关闭 + 焦点落在首个操作 | 只做视觉遮罩 | 读屏用户会被困住 |
| 装饰层 `aria-hidden="true"` | 装饰图带无意义 alt | 读屏会被噪音打断 |
