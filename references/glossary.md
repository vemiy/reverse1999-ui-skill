# 术语表

这些叫法只是给设计和开发之间沟通用的。**任何一个都不许出现在产品界面、用户文档和宣传文字里。** 右列是「对人怎么说」。

| 内部叫法 | 意思 | 对人怎么说 |
| --- | --- | --- |
| 封面 | 一屏只讲一个主张的页面类型 | 首页 / 落地页 |
| 卷宗 | 以阅读为主的详情、长文页 | 详情页 / 文章页 |
| 档案库 | 以检索与列表为主的页面 | 列表页 / 检索页 |
| 米纸 | `#E9DCCD` 的纸面背景，配墨色文字 | 浅色的卡片 / 面板 |
| 锈红 | 唯一的强调色 `#B55829` | 主题色 / 强调色 |
| 切角 | 在角上斜切一刀的形状，游戏里用来做标签与异形框 | 标签样式 / 装饰角 |
| 眉标 | 标题上方那行大写字距小字 | 小标题 / 分类标签 |
| 分段标题 | 上下两条线夹住编号与标题的条 | 第几节 |
| 印章 | 旋转 −5° 的锈红描边戳 | 已核标记 / 状态标 |
| 网点条 | 圆点底纹加锈红边的小块 | 提示条 |
| 竖排英文 | 侧边 90° 排的英文小字 | 侧边装饰文字 |
| 质感层 | 底光、雨丝、颗粒、暗角四层背景 | 背景效果 |
| 变体卡 | 交付说明最前面那三行配置 | 设计配置 |
| 空状态 | 没有数据时显示的一句话与操作 | 暂无内容提示 |
| 指示条 | 2px 的细横线，当前段 4px | 分页指示 / 步骤条 |

## 界面文案的三条规矩

1. 按钮写动作：保存、申请调阅、复制编号。不写「开启旅程」。
2. 英文眉标是中文标题的直译：`// ORDERS` 对「订单」。想不出就只写编号。
3. 不用这套风格的术语描述功能。用户不需要知道什么叫「卷宗」。
